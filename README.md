# Russky.exe

A small funny Python app inspired by Russian culture.

## Features

- Random Russian phrases with French translations
- Russian proverb generator
- Random Russian name generator
- Virtual tea counter
- Russian Mode activation button

## Requirements

- Python 3
- Tkinter

## Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/russky.exe.git
cd russky.exe
```

Run the program:

```bash
python3 russky.py
```
